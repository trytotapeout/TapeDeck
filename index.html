TapeDeck

安全的使用 web3 应用，超低成本构建你的网站，而且永不消失。

下载 0.1.0

macOS · Windows · Linux

tape:// 直接读链

网站文件存在 TapeKit 电路的链上容器里，TapeDeck 直接从公共节点读取，不依赖任何网关服务器。

三条链

BNB Chain、X Layer（区号 2）、Base（区号 3）上的网站都能打开、搜索和体检，各自的节点池，地址栏显示网站所在的链。

按电路名访问

输入 4454.0、#4454@0、1.2.248（X Layer）或 8888.tape 都能打开同一个网站；输入数字串自动尝试所有切分，输入钱包地址打开它持有的所有网站。

哈希和多节点校验

每个文件都核对链上记录的 SHA-256，再找两个不同的节点核对一遍，单个节点作恶伪造不了，不一致时按钮变红。

安全盾牌

打开网站后自动体检整个网站，地址栏的盾牌直接显示结果：绿色没发现问题，黄色要留意，红色发现高危特征，灰色不是链上网站。

安全体检和合约风险

在本机分析网站会请你签什么、有没有骗助记词和盗币工具包，还会检查网站用到的合约：能不能升级、能不能暂停或提走资金，一键打开区块浏览器看源码。

钱包网站体检

输入一个钱包地址，扫描它在三条链上持有的全部网站，逐个体检，按风险排好序，一眼看出哪个有问题。

签名风险解读

无限额授权、授权全部 NFT、离线签名授权、盲签等高危请求翻成一句话，默认按钮是「拒绝」；网站改过代码、换了持有人都会提醒。

钱包不导入私钥

桥接系统浏览器里的钱包扩展（MetaMask 等），不依赖 WalletConnect 这类中心化中继，每次签名都先显示真实来源。

链上身份

在 X Layer 上铸造一枚电路就是你的身份，比如 xlayer23331。个人中心管理身份、容器和门。

加密消息

身份之间端到端加密通讯，和 TapeSend 互通。有新消息时提醒，消息里的 DeWEB 链接点了直接打开。

发送密级文件

文件在本机加密后存进你的容器，钥匙用加密消息交给对方，只有对方能解开，最多 8 MB。

双向 X 身份认证

用 X 发一条认证推文，再用钱包签名存进身份的容器，别人就能确认这个身份真是你的，防止冒充。

DeWEB 应用目录

以卡片列出三条链上所有有首页的网站，显示站长的 logo 或封面，按分类筛选、按标题、编号、持有人搜索。

Fork 二次开发

看到喜欢的网站，一键把全部文件下载到本地文件夹，在它的基础上继续开发。

本地预览和发布

打开本机文件夹按 tape:// 的规则预览，上链前列出问题和要发的交易笔数；满意后一键发到自己电路的容器。

分享链接

网站信息面板一键复制 https 分享链接，能发到 X、Telegram、微信。装了 TapeDeck 的人点开直接打开网站，没装的看到下载页。

锁定和离线兜底

设一个解锁密码，离开电脑时锁住 TapeDeck；文件按 SHA-256 缓存在本机，读链失败时显示上次缓存的版本。

TapeDeck 能证明你看到的内容来自链上、没有被篡改，但判断不了网站作者本身有没有恶意。签名和交易前请自己核对。
