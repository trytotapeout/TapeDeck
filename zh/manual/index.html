操作手册

从安装到发布网站，按步骤讲清楚 TapeDeck 的每个功能。不懂区块链也能照着做。

安装和更新

到首页的下载区选择自己的系统，安装包都发布在 GitHub Releases，每个版本附有 SHA256SUMS.txt 可以核对文件。

  • macOS（Apple 芯片）：打开 dmg，把 TapeDeck 拖进「应用程序」，双击打开。安装包已签名并通过 Apple 公证
  • Windows：运行安装程序，SmartScreen 提示时点「更多信息 → 仍要运行」
  • Linux：给 AppImage 加上执行权限（chmod +x）再运行

TapeDeck 启动时会检查新版本，有新版本时弹窗提示，书签和设置升级后都会保留。也可以在菜单里点「检查更新…」：mac 在 TapeDeck 菜单，Windows 和 Linux 在帮助菜单。

打开链上网站

链上网站存在 BNB Chain、X Layer、Base 三条链上，用一串数字表示。在地址栏输入就能打开：

输入效果
4454.0BNB Chain 上的网站（不带区号）
1.2.344X Layer 上的网站（区号 2）
1.3.5Base 上的网站（区号 3）
12330没写点时，TapeDeck 会试所有可能的拆法，找到的网站各开一个标签
0x… 钱包地址打开这个钱包在三条链上持有的全部网站
example.com普通网页照常打开，但不受链上校验保护

别人分享给你的 gettapedeck.com/open/?… 链接，点开后会唤起 TapeDeck 打开对应网站；没装 TapeDeck 的人会看到下载按钮。

常用快捷键

Windows 和 Linux 把 ⌘ 换成 Ctrl。

⌘ T / ⌘ W / ⌘ L新标签页 / 关闭标签页 / 跳到地址栏
⌘ D把当前网站加入或移出「我的关注」
⌘ F页内查找
⌘ + / ⌘ - / ⌘ 0放大 / 缩小 / 实际大小

地址栏右边可以把网页切成平板或手机尺寸，每个网站会记住你的选择。

看懂安全提示

地址栏的盾牌

网站打开后会自动体检，盾牌的颜色就是结论：

  • 绿色：没发现问题
  • 黄色：有需要留意的地方，或者加载了不在链上的外部脚本
  • 红色：发现高危特征，比如骗助记词、偷偷把资产授权出去
  • 灰色：普通网页、本地预览，或者还没体检完（体检中会闪烁）

点盾牌能看完整报告：网站会请你做哪些钱包操作、代码里写死的地址是合约还是普通钱包、这些合约的主人能做什么。体检全在你的电脑上完成，不上传任何内容。

「链上」按钮

盾牌旁边的「链上」按钮打开网站信息面板：持有人、文件指纹、上链时间、分享链接和打赏。按钮上的提示要留意：

  • 节点结果不一致（按钮变红）：两个节点读到的内容不同，先别在这个网站上签名
  • 含外部脚本：网站有部分内容来自外部服务器，这部分不受链上校验保护
  • 离线缓存：读链失败，显示的是上次缓存的版本
  • 持有人已变、有更新：网站换了主人，或者首页在你上次访问后改过

签名和交易确认

网站请钱包签名或发交易时，TapeDeck 先弹窗用一句话说明这次操作会做什么，再交给钱包扩展。无限额授权、授权全部 NFT、Permit 离线授权、挂单、盲签这类高危操作，默认按钮是「拒绝」。看不懂的操作就拒绝，不会有损失。

这些检查能降低风险，但「没有发现问题」不等于绝对安全。TapeDeck 能证明内容来自链上、没被篡改，判断不了网站作者本人有没有恶意。

连接钱包

TapeDeck 不导入私钥，签名仍由你系统浏览器里的钱包扩展（MetaMask 等）完成。

  1. 点工具栏的「连接钱包」，或在网站里点连接
  2. TapeDeck 在系统浏览器打开一个本机页面，在那里选好钱包扩展并授权
  3. 回到 TapeDeck，确认是否把地址给这个网站

钱包扩展里看到的来源会是 127.0.0.1，这是 TapeDeck 的本机桥接页面，属于正常情况。钱包按钮变红并显示 ⚠ 时，说明钱包不在 X Layer 上，点一下就能切过去。要断开钱包，去「设置」或菜单「钱包 → 断开钱包」；授权过的网站也可以在设置里逐个取消。

新标签页

新标签页左边的菜单分四组：

  • 去中心化网站：我的关注、最近访问
  • 创建网站应用：上传发布应用、激活网关域名、钱包网站体检、TapeCode Plus（用 AI 生成网站）
  • 安全链上应用：查保管箱资产、双向身份认证、发送密级文件
  • 更多：个人中心、加密消息、使用帮助、设置

「我的关注」就是书签，加入前会先做一次安全体检。「最近访问」最多记 200 个网站。这些都只存在你的电脑上。

身份和个人中心

身份是你在 X Layer 上持有的一枚电路，显示成 xlayer23331 这样的 ID，可以理解成链上的护照，自带一个保管箱。加密消息、密级文件、X 认证、发布网站都要用到身份。

  1. 连接钱包，工具栏会显示「注册身份」
  2. 点它，在钱包里确认两笔交易：买 1 块积木，再用它搭出身份
  3. 注册好后工具栏显示当前身份，有多个身份时点开就能切换

个人中心（更多 → 个人中心）里能看积木数量并购买，查看每个身份的保管箱和资产，开通保管箱、开通加密通讯、去做 X 认证。

加密消息

身份之间可以互发端到端加密的消息，和 TapeSend 互通。

  1. 开通加密通讯：在个人中心为身份开通。钱包会让你签两次同一段文字，再发 1 笔交易。签名文字里写的是 www.tapesend.com，钱包提示域名不一致属于正常
  2. 写消息：更多 → 加密消息，收件人填对方的身份 ID 或电路地址，TapeDeck 会检查对方能不能收，并显示对方的 X 认证状态。发送需要 1 笔交易
  3. 读消息：签名一次解锁后能看正文。消息里的链上网站链接会变成按钮，点了在 TapeDeck 里打开

TapeDeck 每分钟查一次有没有新消息，有就在菜单上显示未读数并发系统通知。

发送密级文件

  1. 新标签页 → 发送密级文件，选文件（最多 8 MB），填收件人
  2. 文件在你的电脑上加密后存到自己的保管箱，钥匙通过加密消息发给对方。钱包最多确认 3 次
  3. 对方在收件箱看到「密级文件」，点「下载并解密」保存

上传途中可以暂停，之后接着传。注意密文会永久留在链上，对方解开后能转给别人，技术上拦不住。

双向身份认证

证明某个身份和某个 X 账号是同一个人控制的，别人就能在你的身份旁看到 @用户名。

  1. 按界面生成的内容发一条推文，里面必须保留「TapeDeck 认证：你的钱包地址」这一行，其他文字可以改
  2. 把推文链接贴回来，钱包签一份声明，存进这个身份的保管箱
  3. 完成后任何人都能输入你的身份 ID 查到认证结果

删推就等于解除绑定。绑定会公开这个钱包的余额和交易记录，删推也收不回，建议用非主力钱包。

查资产和查钱包

查保管箱资产

填身份 ID（如 xlayer23331）或电路地址（如 1.2.248），就能看到保管箱地址、持有人和里面的常见资产，不用连钱包。其他代币和 NFT 可以点链接到 OKLink 查看。

钱包网站体检

输入一个钱包地址，TapeDeck 会找出它在三条链上持有的全部网站，逐个做安全体检，按风险排序。发现高危的网站要连点两次才会打开。

发布自己的网站

发布目前只支持 X Layer，还在实验阶段。开通费和 Gas 是真实花费，建议先用一个小网站试一次。

  1. 准备一个文件夹，根目录要有 index.html。还没有网站的话，可以先用 TapeCode Plus 让 AI 生成一个
  2. 新标签页 → 上传发布应用，选好文件夹，先在本地预览。改了文件，标签会自动刷新
  3. 点地址栏左边的「本地」按钮看预检查：要传多少文件、几笔交易、有没有错误和警告
  4. 没问题就点「继续发布」，发布页会列出计划和预估花费
  5. 钱包通常确认 2 到 3 笔交易（开通保管箱、授权临时钱包、充值上传用的 Gas），之后的上传自动完成，用剩的 Gas 会退回

几点要知道：

  • 链上文件只增不改，内容变了的文件要换个文件名；只有根目录的 index.html 可以整个替换
  • 中途暂停、关掉应用或断网，再打开发布页能接着传
  • 想在网站目录里有好看的卡片，可以在根目录放 logo.png（正方形，推荐 256×256）和 cover.png（16:10，推荐 640×400），每张不超过 50 KB
  • 想让没装 TapeDeck 的人用普通浏览器打开，到「激活网关域名」激活一次

锁定和设置

在「设置 → 解锁密码」设一个至少 6 个字的密码后，工具栏的锁按钮就能用了。锁着时网页都会藏起来，网站也不能请钱包签名。

  • 输错 3 次后要等一会儿，错得越多等得越久，最多 15 分钟
  • 忘了密码，可以在锁屏上「清除本机数据并重置」。会清掉最近访问、我的关注、网站授权和缓存，链上的东西不受影响

设置里还能切换中文和英文、给三条链填自定义节点、取消网站的钱包授权、清除内容缓存。

常见问题

TapeDeck 会碰我的私钥吗？

不会。钱包一直在你自己的浏览器扩展里，TapeDeck 只把签名请求转过去，并在之前把风险讲清楚。

盾牌是绿色，就一定安全吗？

不一定。体检是按已知的作恶特征检查，能挡住常见的骗局，但不能保证网站作者没有恶意。签名前仍要看清楚弹窗里写的内容。

打不开网站怎么办？

先确认数字和链对得上，比如 X Layer 的网站要带区号 2。公共节点偶尔会慢或失败，可以稍后重试，或者在设置里换成自己的节点。还是不行可以到 GitHub 反馈。
